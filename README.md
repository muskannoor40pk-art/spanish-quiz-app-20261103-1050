## Overview
The Quiz App is a lightweight, single-page application built to provide an engaging trivia experience. Optimized for users across Latin America and Spain, it offers a seamless interface for testing knowledge, tracking progress, and competing for the best score. Whether for educational purposes or entertainment, this tool is designed to be accessible and fast.

## Features
*   **Dynamic Progress Bar:** Visual feedback to track how much of the quiz remains.
*   **Timed Challenges:** Built-in timer to add excitement and urgency to each question.
*   **Instant Scoring:** Real-time feedback provided upon completion.
*   **Responsive Design:** Fully fluid layout using Flexbox and Grid, optimized for mobile and desktop.
*   **Restart Functionality:** Easily reset the quiz to try again without reloading the page.
